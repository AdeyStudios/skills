# Sources and adoption

Reviewed 31 October 2026. This is original, conditional guidance informed by a founder-approved native redesign and the sources below. That project motivated this draft; it was not an independent evaluation of the draft skill.

| Source | Useful contribution | Boundary |
| --- | --- | --- |
| [Elya: Redesign Existing Projects](https://github.com/elayadesign/redesign-skill) | Diagnose hierarchy, surfaces, component choices, feedback and missing states before changing code. | Web-specific fonts, CSS scales, fixed timings and small-edit defaults do not govern a native app or override an explicit restructure. |
| [Elya: AI Design Skills](https://github.com/elayadesign/ai-design-skills) | Connect the primary action to an intentional visual direction. | Do not insert landing-page sections into an in-app task. |
| [Owl Listener: Designer Skills](https://github.com/Owl-Listener/designer-skills) | Focused typography, density, hierarchy, platform and feedback lenses. | Verify specific platform claims; avoid rigid component or navigation rules. |
| [Muomi](https://muomi.vercel.app/) | A product reference for purposeful central content, distinct surfaces and direct mobile controls. | A mobile website is not proof of native behaviour. Transfer principles, not its unrelated hydration features. |
| [Apple: Motion](https://developer.apple.com/design/human-interface-guidelines/motion) and [Gestures](https://developer.apple.com/design/human-interface-guidelines/gestures) | Meaningful feedback, familiar interaction, alternatives to gestures and optional motion. | Follow current platform behaviour; this skill prescribes no animation duration or universal gesture. |
| [Android: Navigation](https://developer.android.com/guide/navigation) and [multiple back stacks](https://developer.android.com/guide/navigation/backstack/multi-back-stacks) | Navigation/state conventions, including retaining separate flows. | Do not assert Android cannot retain tab history or prescribe one back-stack structure for every app. |

Lessons retained from the redesign: review the whole task rather than typography alone; use platform interaction opportunities where useful; test keyboard and lifecycle states; inspect actual large-text renders; treat voice denial and paging failure as part of the experience. Do not require voice, automatic pagination, coloured topic cards or a particular four-tab arrangement in unrelated products.

The founder's approval supports the direction for that project. Comparative agent testing and downstream product impact remain unestablished. External sources retain their own licences; no external skill installation is required.
