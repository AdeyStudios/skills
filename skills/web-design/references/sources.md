# Sources and adoption

Reviewed 31 October 2026. This workflow combines the collection's existing design judgment with lessons from an interface redesign. It remains a working draft, not a proven conversion method.

- [Elya: Redesign Existing Projects](https://github.com/elayadesign/redesign-skill): a useful diagnostic across hierarchy, components, motion and state coverage. Adapt the audit to the brief; do not adopt fixed fonts, CSS values, layout recipes or small-edit constraints universally.
- [Elya: AI Design Skills](https://github.com/elayadesign/ai-design-skills): useful attention to audience, promise, action and coherent visual direction. Its landing-page structure is conditional on page purpose. No mandatory FAQ count, hero gradient or font swap is retained.
- [Owl Listener: Designer Skills](https://github.com/Owl-Listener/designer-skills): focused lenses for hierarchy, typography, spacing, information density and feedback. Independent checks can support a coherent direction but cannot replace understanding the task.
- [W3C: Reflow](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html): guidance for retaining information and functionality as content enlarges and the viewport narrows, with exceptions for genuinely two-dimensional content.
- [W3C: Focus Not Obscured](https://www.w3.org/WAI/WCAG22/Understanding/focus-not-obscured-minimum.html): guidance relevant to sticky headers, footers and overlays. Our preferred check is to keep the active control clearly usable, not merely to scrape past a minimum criterion.

These sources are linked for provenance, not required installations. Source claims, current accessibility requirements and local style preferences have different authority. External sources retain their own licences. Review the actual product and current standards before prescribing an implementation.
